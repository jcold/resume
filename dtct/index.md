## 项目说明：交通银行总工会福利平台

交行员工通过内部健康类 APP 运动获得积分，但没有可用的兑换渠道。系统必须嵌进这个 APP，并且部署在客户内网，由客户掌控运行环境。公有云商城解决不了身份接入、积分不过域，以及安全制度要求系统完全可控这几件事。

1. **业务问题。** 为交通银行总工会建设积分乐园，作为内部 APP 的兑换渠道。员工用运动产生的积分兑换商品，品类包括电商平台商品和客户自有供应商商品。系统要完成单点登录、积分兑换、消息通知和混合支付，并在客户内网独立运行。
2. **本人职责。** 项目总负责。从方案、讲标和需求沟通开始，组织研发、客户现场实施和生产上线。运行环境是内网中的多台虚拟机，用 Docker 与 Docker Compose 分别运行业务服务和数据库、缓存、检索、消息队列等基础组件。代码经 Jenkins 调用 Ansible 发布。上线后继续负责二期、三期、扩容，以及运行中的问题处理。
3. **上线后的使用。** 2018 年中在客户内网生产环境上线，并交付使用手册、部署说明和交接材料。上线后做过容量扩容。二期做了自有供应商管理，三期继续补充需求。服务期间系统用于员工积分兑换，并由项目侧承担日常维护和故障修复。
4. **可复用成果。** 内网交付收成一套可重复使用的方法：外部构建镜像，Docker Compose 在多台虚拟机上启动，Ansible 做初始化和发布，Jenkins 做发布入口。单点登录、积分兑换、消息通知、混合支付和自有供应商管理，是福利平台上的能力，在这个项目里按客户 APP 和内网约束做成可运行的接入。后续同类项目沿用这套部署方式和接入清单。部署时单独确认的事项也写进了文档：虚拟机与网络分区、出网代理、内网域名，以及哪些数据不能离开客户环境。
