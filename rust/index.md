### 2. Abox Note｜跨平台 Markdown 笔记

开发以 Markdown 纯文本为核心的笔记产品，关注记录、整理和长期保存的使用体验。

- 持续完善应用功能、跨平台构建与发布流程。

**项目体现：** 跨平台产品研发、不同技术组件的协作，以及从产品需求到具体实现的工程实践。

### 3. DaoBox｜桌面 Markdown 知识库

开发面向本地文件与知识整理的桌面应用，探索 Markdown 文件管理、版本控制与内容发布的结合。

- 结合桌面应用与 Rust 服务端组件，实现本地知识内容管理相关功能。
- 集成基于 libgit2 的版本管理能力，涉及状态查看、提交、同步、历史与冲突处理。
- 围绕本地文件的可控性、内容组织和持续维护开展产品开发。

**项目体现：** 桌面软件开发、文件与版本管理、跨组件集成及复杂功能的组织实现。
